# Jarvis Workbench 官网 — 各区块结构与动画设计 v1.0

> 前置：《网站架构设计.md》。本稿逐区块给出结构、视觉规格与动画参数。
> 动画纪律继承工具本体的 motion-spec 思想：**分层、token 化、同屏 ≤1 组编排、reduced-motion 全降级**——同一套「手感」是比配色更深的「与工具紧密相关」。

---

## A. 全站 token 定稿

### A.1 色彩（Tailwind v4 `@theme`）

| token | 值 | 用途 |
| --- | --- | --- |
| `--void-0` | `#04070d` | 页面底（最深） |
| `--void-1` | `#0a101c` | 面板底 |
| `--void-2` | `#101a2b` |  raised 卡片/终端底 |
| `--arc` | `#3fd9f3` | 弧反应堆青：主描边、链接、激活态 |
| `--arc-dim` | `rgba(63,217,243,.35)` | 次级线条、网格线 |
| `--arc-glow` | `0 0 24px rgba(63,217,243,.25)` | 发光阴影（唯一阴影语言） |
| `--gold` | `#f0b64d` | repulsor 金：主 CTA、「人」的角色（审核/建任务） |
| `--text-hi` / `--text-mid` / `--text-lo` | `#e8f4f8` / `#9db3c4` / `#5a7080` | 三档文本 |
| 状态六色 | `#8a93a8 #3b82f6 #f59e0b #8b5cf6 #10b981 #ef4444` | 与工具 DESIGN.md 同色相，提饱和 10% 用于 HUD 描边 |

### A.2 动效分层与允许值（`src/lib/motion.ts`）

| 层 | 场景 | 参数 |
| --- | --- | --- |
| L1 微交互 | hover/按压/focus | `140ms / cubic-bezier(.2,0,0,1)`（与工具 L1 同值同曲线），仅改色/描边发光/≤2px 位移 |
| L2 浮层 | FAQ 展开、移动抽屉、tooltip | 入 `200ms scale.96→1+淡入 / cubic-bezier(.32,.72,0,1)`；退 ≤ 入×0.7 |
| L3 滚动编排 | 区块入场、列表 stagger、换列飞行 | 入 `400ms y16→0+淡入`；stagger `60ms`、单项上限 `300ms`；飞行 spring `gentle` |
| L4 环境循环 | 扫描线、反应堆旋转、雷达环、终端光标 | 1.6s–8s linear/infinite；**只动 opacity/transform，绝不动布局** |

规则（同工具口径）：时长/曲线只允许上表全集；滚动本身永不驱动复杂逐帧计算（用 `whileInView` 一次性触发，不做 scroll-linked 视差堆砌，性能预算见 §E）；同屏同时运行的 L3 ≤1 组。

### A.3 通用 HUD 元件（`components/hud/`，先造后用）

| 元件 | 结构 | 动效 |
| --- | --- | --- |
| `BracketFrame` | 四角 L 形描边的绝对定位 span ×4 | 区块入场时四角从外 8px 收拢到位（L3 400ms，随后静止） |
| `PanelTitle` | 小号等宽字标签 + 左侧 4px 青色短横 | 短横 scaleX 0→1（200ms）先于标题淡入 |
| `ScanSweep` | 面板内 1px 高横向渐变条 | 入场上路过一次（600ms，一次性）；面板 hover 时再扫一次 |
| `Typewriter` | 等宽文本 + 光标块 | 30ms/字；光标 1s blink（L4） |
| `HudChip` | 胶囊描边小标签 | 无自有动画，随父列表 stagger |
| `GlitchText`（慎用） | 双层色散文字 | 仅 Hero 主标题出现 1 次、300ms，全站限 2 处 |

## B. 全局壳（S0）

**结构**：`fixed` 顶栏 64px（`--void-1/70 + backdrop-blur-xl`，底部 1px `--arc-dim` 边线）｜Logo=小型反应堆 SVG（同心环+三角）+ 字标「JARVIS WORKBENCH」等宽字距排版｜右侧锚点组 + 金色实心「下载」按钮｜顶栏下沿 2px 滚动进度光束（青色，scaleX 跟 scrollY）。背景层：CSS 网格底纹（4% 透明度）+ 两团缓慢漂移的青/金辉光（transform 60s 循环）+ 极稀疏噪点图。

**动画**：首屏加载 = 「系统上线」序列（见 C1 前置）：Logo 环 800ms 起转 → 顶栏边线从左到右亮一次（scanline 600ms）→ 页面内容各区块随后按滚动触发。**滚动过 Hero 后顶栏压缩至 56px 并加深度描边**（200ms，唯一 scroll-linked 效果，其余无视差）。锚点跳转平滑滚动；当前区块对应导航项青色下标（layoutId 滑动，同工具 Sidebar 竖条手法）。

**首页常驻文档侧栏（二期追加）**：`DocsSideRail`——左缘 fixed HUD 悬浮面板（边框+四角青色 L 括角+青辉光/落影双层投影+backdrop-blur），题签 FIELD MANUAL 链 /docs、01–09 章链各文档页；分档：≥2xl 全量「章号+章名」、xl–2xl 章号轨+hover 浮出章名、<xl 隐藏；动效仅 L1（140ms 色彩/透明）。方案已经用户冻结（「就按现有方案，后续再说」），细则与几何实测见《二级页面架构与内容设计》§9 追加项。

## C. 区块逐构

### C1 · S1 Hero「JARVIS 在线」

```
<section id="hero"> 左 55% ┆ 右 45%（<960 上下堆叠）
  左: 状态行 [● SYSTEM ONLINE · v0.0.4 beta]（金色小字等宽）
      H1 「你的 AI Agent 团队，需要一块真正的看板。」
      打字机副行：「贾维斯，把需求拆解后交给 Agent 执行。」
      一句话定位段（本地桌面 · 人建任务 · Agent 执行 · 强制人审）
      CTA: [下载 for macOS] (金实心)  [看它怎么转 ↓] (青描边)
      小字: 支持 Apple Silicon / Intel · 仅本机运行，数据不出电脑
  右: 全息看板投影装置：
      BracketFrame 内 3 列迷你看板线框(需求池/执行中/待审核)
      + 底部弧反应堆雷达环（卡片仿佛由其上"投影"而出）
```

**动画序列（t 从区块可见起算）**：雷达环持续慢转（L4）→ 0ms 状态行淡入 → 120ms H1 逐行 rise（400ms）→ 400ms 打字机副行启动 → 600ms 右列三列看板线框自下而上「全息展开」（clip-path 由底向上 + 扫描线过一次，L3 一次性）→ 900ms 演示循环开跑：一张金边卡片从「需求池」飞行到「执行中」（列变色）→ 停 1.6s → 再飞「待审核」（紫 glow 脉冲一次）→ 循环。**该循环是 L4 性质的常驻动画**（单一元素、只动 transform/opacity），但 reduced-motion 下直接定格在「待审核」终态。CTA 按钮 hover=金色提亮+glow 增强（L1）。

### C2 · S2 三条铁律

**结构**：`PanelTitle「核心原则 / PRIME DIRECTIVES」` + 三等分卡片横排。每卡：顶部大号罗马数字 Ⅰ/Ⅱ/Ⅲ（青色描边字）+ 图标（用户/机器人/盾牌，lucide）+ 铁律短句 + 一行反例小字（灰色，`划掉样式`：「Agent 自己验收自己 ✗」等）。文案：Ⅰ 任务由人建立并排序；Ⅱ Agent 凭租约认领执行（30 分钟心跳续租）；Ⅲ 一切产出必经人工审核方生效。

**动画**：三卡 stagger 60ms rise 入场（一次）；卡片 hover 时各自 ScanSweep 扫一次（L1 内嵌的轻量 L4）+ 边框由 `--arc-dim`→`--arc`。铁律 Ⅲ 的盾牌图标常驻极缓呼吸（opacity .8↔1，3s）——全区块唯一常驻动效，强调「审核」分量。

### C3 · S3 一块任务卡的旅程（状态机流水线）

**结构**：全宽交互组件。顶部标题 + 「▶ 播放 / 〈 〉步进」控制条（等宽小按钮）。主体为横向流水线：7 个节点（需求池·待执行·执行中·待审核·已完成 + 受阻/异常两个下挂分支节点），节点=六边形 HUD 徽标（各持状态色）+ 连线（青色虚线箭头，失败路径红色虚线）。节点下方是**详情槽**：随当前步骤切换一张小卡（60 字内说明 + 一个关键细节：如「租约 30min，过期转异常」「审核必填 建议/原因/详情」「REVIEW 出口只有通过/驳回」）。

**动画**：点播放后一张金色任务卡沿连线逐节点行进（transform 位移，段间 700ms ease-settle 缓动 + 到点时节点状态色 glow 脉冲一次）；行进到哪步，对应连线由 dim→实亮、详情槽卡片做 L2 退/入（退 140 / 入 200ms）。「执行中」阶段任务卡下挂一条 1.6s 流动进度条（直接复用工具 L4 `--animate-flow` 语言的移植）。整段播完停在「已完成」绿色 + 对勾 pop（`springs.pop` 移植）。**同屏仅此一组编排**——本区块可见期间 Hero 循环暂停（IntersectionObserver 互斥，防双常驻）。移动端流水线纵排，卡片行进改为逐行高亮。

### C4 · S4 能力模块（座舱面板）

**结构**：左 40% 为**一个**大幅模块示意区（五个模块共用一个 BracketFrame 画框，内容整体切换），右 60% 为竖排可点列表：看板（三视图+拖拽换列+分组泳道）/ 审核（队列逐条批、通过驳回）/ 技能库（预置 94 条、三来源导入、12 分类）/ Agent 接入（MCP 26 工具 + REST、Token 分组）/ 设置与审计（9 Tab、导入导出、备份、审计日志）。示意区内各模块用**同一套迷你线框语言**画不同构图（看板=三列格子；审核=diff 视图+两按钮；技能=搜索框+分类 chips；接入=终端块滚出 `tools/list`；设置=分组列表）——全是抽象线框，不放真实截图（界面仍在快速迭代，防过期）。

**动画**：列表项点击/键盘可达；切换时旧构图 140ms 淡出下沉 4px，新构图 200ms rise 入 + 画框内 ScanSweep 扫一次；右侧选中项青条指示（layoutId 滑动，同工具 Sidebar 手法）。列表首次入场 stagger 60ms。hover 未选中项=文字提亮+左侧圆点变青（L1）。

### C5 · S5 四步开机（上手引导）

**结构**：纵向四步，每步一行：左侧步骤塔（编号 + 垂直连线，形似装配单）｜右侧内容卡。① 安装：拖 .app 进 Applications + Gatekeeper 提示条（可复制 `xattr -cr` 命令的终端小卡）；② 建第一张任务：迷你表单线框 + 「或把这段模版发给你的 AI 助手」（可复制的建任务 JSON 摘要）；③ 接入 Agent：深色终端窗，光标逐字打出 MCP 配置——`"url": "http://127.0.0.1:7788/mcp", "headers": { "Authorization": "Bearer atb_…" }`，旁注「Token 在 设置→Token 签发，明文只显示一次」；④ 唤醒与验收：对话气泡「贾维斯，认领一块任务」→ 切到审核视图线框（diff+通过按钮），注「产出物不过你的手，不算完成」。每步底部小字标注预计耗时（约 1 分钟级）。

**动画**：各步内容卡走通用 L3 rise+stagger；**步骤塔垂直连线在滚动经过时自上而下描亮**（用一次性 clip 高度过渡 400ms 模拟，非 scroll-linked 持续计算）；步骤 ③ 的终端打字机**仅在该卡首次可见时播放一次**（60ms/字，约 3s，播完光标常驻 blink）；①/② 的可复制代码块 hover 浮现「复制」微按钮，点击后按钮换成对勾 pop 140ms（移植工具 L4 徽标语言）。

### C6 · S6 本地优先

**结构**：左文案（标题「一台电脑，就是一个完整的指挥中心。」+ 四条短列表：仅监听 127.0.0.1 / 数据在本机 SQLite `~/.jarvis-workbench/` / 无账号无云端 / 操作全程留痕可审计），右为**环心示意**：圆心一颗芯片图标（本机），外环四个卫星点（看板数据/Agent 通道/产出物/审计日志）以青色轨道线相连，环外一道红色虚线划出「外网 No entry」边界并带 ⃠ 断口符号。

**动画**：轨道环慢转（L4 12s）；卫星点 hover 亮标签 tooltip（L2）；「外网边界」入场时红虚线从中间向两描边画出（clip 一次性 600ms）后叠加一个极轻的「撞击熄灭」光点——表达「什么都出不去」。文案列表 stagger 入场。

### C7 · S7 下载 CTA「启动」

**结构**：居中大区块。标题「READY TO DEPLOY」+ 最新版徽章（读自内容常量，指向 Releases latest）+ 两张平台卡：**Apple Silicon (arm64)** / **Intel (x64)**，卡内：架构小图标、dmg 文件名模式、SHA256 校验说明链接、主按钮；下方三行小字须知（ad-hoc 签名首开右键打开；beta 通道声明：功能可用但仍在验收迭代；升级先删旧版本）。Windows/Linux 不放卡片，只在小字留一行「Coming later」。**不做假下载计数**。

**动画**：两卡 stagger 60ms 入场 + 首次进入视野时反应堆环从两卡背后展开一次（弧光扫出，1 次性 800ms）；主按钮常驻极缓的辉光呼吸（gold shadow 0.14↔0.25，3s，全站唯一常驻 CTA 动效）；hover=提亮+scale .98（按压，工具 Button 语言）。

### C8 · S8 FAQ + S9 Footer

**结构**：FAQ 单列手风琴 7 问（打不开/已损坏怎么办 · beta 能日常用吗 · 支持哪些 Agent · Agent 会不会绕过审核 · 数据怎么备份迁移 · Windows/Linux 何时来 · 收费吗）；答案区含命令的放行内代码。Footer：Logo 灰版 + GitHub Releases 链接 + 锚点回显 + 「Jarvis Workbench · Local-first mission control」。

**动画**：FAQ 展开=L2 浮层语言（面板 rise 200ms/退 140ms + 加号旋转 45° 成叉）；同屏保持至多 1 项展开（旧项自动收起，退场生效）。Footer 无动画。

## D. 文案与「贴合工具」的缝合点（设计意图备忘）

1. 状态色直接沿用工具六态色相 → 用户在站内看到「待审核=紫」和工具里一致；
2. 激活指示 layoutId 滑动、按压 scale .98、退场≤入场×0.7、stagger 60ms 上限 300ms——全部移植 motion-spec v1.2 的档位语义（数值按网站场景放宽一档）；
3. 「贾维斯，…」唤醒词、`atb_` Token、127.0.0.1:7788、30 分钟租约这些**真实机制原样入文案**，科幻壳里装的是真参数；
4. 金色专属「人的介入」（建任务/审核/主 CTA），青色专属「系统与 Agent」——色彩即产品哲学：人主导，Agent 干活。

## E. 性能与降级预算

- 常驻动画 ≤2 个/屏（雷达环/轨道环/CTA 呼吸各占其一，互斥调度），全部 transform/opacity；
- 区块动画一律 `whileInView once` + IntersectionObserver，离开视口不重播（Hero 循环与 S3 播放器互斥除外）；
- 零第三方请求、零字体网络加载（系统栈 + 等宽栈，不引 webfont；若评审要求更硬的西文标题字感，再议本地子集化 woff2 ≤30KB）；
- `prefers-reduced-motion: reduce`：打字机→直接给全文；所有 rise/飞行→纯 opacity 140ms；L4 循环全停；S3 播放器退化为步进阅读；
- JS 目标：首包 ≤125KB gzip（motion 占大头；二期启用 react-router 后由 ≤120KB 上修，M6 实测 124.08KB、含首页常驻侧栏后终值 124.43KB，出处见《二级页面架构与内容设计》§9 追加项）；构建门禁 `typecheck + build`，与工具惯例对齐。

## F. 实现切片顺序（评审通过后）

```
T1 工程初始化 + tokens + hud 元件 + 全局壳/背景/顶栏      → 可滚空页
T2 S1 Hero（含全息看板与飞行循环）                        → 首屏成立
T3 S2 + S6 + S7 + S9（静态向区块 + 下载卡）               → 骨架完整
T4 S4 能力模块（五构图 + Tab 切换）
T5 S5 上手引导（终端打字机 + 复制交互）
T6 S3 状态机播放器（最重交互件，压轴）
T7 FAQ + 互斥调度/reduced-motion 收口 + 三档视口截图走查（320/960/1280）
```

每片完成即浏览器实测走查（含窄档），截图核对后提交，不等汇总。
