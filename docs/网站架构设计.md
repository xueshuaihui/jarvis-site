## 1. 定位与目标

| 项 | 结论 |
| --- | --- |
| 网站性质 | Jarvis Workbench（贾维斯客户端）的**产品介绍 + 使用引导**官网，单页长滚动 Landing |

## 4. 技术选型

| 层 | 选择 | 理由 |
| --- | --- | --- |
| 构建 | Vite 7 + React 19 + TypeScript | 用户拍板；与工具 `@atb/web` 同栈，心智复用 |
| 样式 | Tailwind CSS v4（`@theme` 定义本站 token） | 工具同款做法；token 单点管理 |
| 动效 | `motion`（motion/react）+ CSS transition/keyframes | 滚动编排 `whileInView`、换列飞行 `layout`；微交互走 CSS——沿用工具 motion-spec 的「分层不混轨」纪律 |
| 图标 | lucide-react | 与工具一致 |
| 图表类 HUD 图 | 手写 SVG（状态机、环形网络图） | 零重依赖，动画可控 |
| 路由 | 无（单页锚点滚动） | 本期只有 Landing；为二期文档页预留 react-router 安装位即可，不预装 |
| 部署 | 暂不定（可 GitHub Pages / 任意静态托管）；`npm run build` 产出 `dist/` 即可 | 本期交付本地可跑 |

约束：**零运行时数据请求**——版本号、下载数等一律不远程拉取（避免 CORS 与失效），全站离线打开可用；不引入分析埋点。

## 5. 视觉系统（科幻向 token 总纲）

> 逐组件的 token 值在《结构与动画设计》§A 定稿，此处定方向与来源。

- **底色体系**：深空蓝黑三档（对应工具 `bg-app/surface/raised` 的科幻化平移），全站恒定深色、无浅色切换（HUD 无白昼形态）。
- **主色**：弧反应堆青（cyan→teal 微渐变）承担一切「活性」元素：线条、描边、发光；**辅金**（repulsor gold）只留给主 CTA 与「人工审核」语义——金色=人的介入，是整站叙事色。
- **状态色**：直接借工具六态色相（backlog 灰 / ready 蓝 / running 琥珀 / review 紫 / done 绿 / failed 红），但提饱和、以描边+glow 的 HUD 形式呈现——让用过工具的人在网站上「认得出自己见过的颜色」。
- **质感元件**：细网格底纹、四角 bracket 取景框、扫描线扫过、虚线雷达环、单等宽字体的终端/代码块（JetBrains Mono，与工具字族一致）。
- **字族**：中文苹方 + 西文 Inter（标题可用更硬朗的字重），数字/代码一律等宽叠 `tabular-nums`（继承工具规范）。
- **克制红线**：特效服务于「指认信息」，不做无意义粒子雨/3D 模型堆砌；全站动画 token 化、reduced-motion 全降级（细则见动画稿）。

## 6. 响应式与验收口径

- 断点：≥1280 全展开 / 960–1279 双栏收单栏、HUD 图缩尺 / <960 移动档（打字机保留、换列飞行简化为步进、背景动效降采样）。
- **验收硬规则（继承项目惯例）**：每个布局结论必须在 320 / 960 / 1280 三档截图复验，防「宽视口才成立」的假结论；`prefers-reduced-motion` 下无位移动画残留。
