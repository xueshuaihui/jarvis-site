## 1. 定位与原则

- 文档区 = 产品的**对外操作手册**：比工具内帮助完整、比仓库源码文档收敛——只写用户/Agent 开发者用得上的操作细节。
- 设计主题延续一期 HUD 科幻风与 motion-spec 分层纪律；**但文档区动效预算降级**：正文是读的不是看的，动画只保留壳层（导航、页头、切换），表格与段落不挂 scroll 动画（见 §5）。
- 红线继承：线框示意（不放真实截图）、零外链请求、零统计、macOS-only、版本号全站只出现一次（见 §6 版本呈现规则）、不虚构能力（§2 词表）。

## 3. 信息架构（IA）

### 3.1 路由形态 ——〔F1 已拍板：方案 A react-router SPA〕

- **方案 A（推荐）：react-router SPA**。一期架构稿预留的「react-router 安装位」启用；`/` 首页不变，`/docs/*` 文档区共享壳组件，页间切换有 L2 过渡、侧栏状态常驻。代价：首 bundle +约 10–15KB gzip（预算复核 §7）。
- **方案 B：Vite MPA 多入口**。每文档页独立 html，零 router 依赖、首屏最小；代价：跨页硬刷新无过渡、共享壳靠复制、一期探针脚本要扩多入口。
- **方案 C：文档区单长页 + 锚点**。零新依赖；与「详细手册」体量（§2 十七个事实域）不匹配，判为不可行仅备案。

## 5. 动画规范（文档区特化，仍守 motion-spec 分层）

| 层 | 用在哪 | 规格 |
| --- | --- | --- |
| 页面切换（新增 L2-doc） | `/docs/*` 路由间 | 出 140ms fade+y-4，入 200ms fade+y:16→0，EASE_EMPHASIS；同屏只此一个编排组 |
| L3 rise | 仅 PageHeader 与 Hub 九宫格 | 400ms / stagger 60ms，`whileInView once` |
| L1 | 导航树 hover/active、Copy 按钮 Check pop、矩阵十字高亮 | 140ms EASE_SETTLE，layoutId 竖条 |
| L4 环境 | 仅 Nav 滚动进度条 + Backdrop（复用一期）；**正文区禁用一切循环动画**（阅读专注） | — |
| 滚动进场 | 正文段落/表格**一律不做** scroll reveal（读的内容不该藏） | — |

- reduced-motion：页切换退化为瞬切；Hub 九宫格直出；矩阵十字高亮保留（非动画）。
- 性能预算：文档区每页 DOM 节点目标是表格化堆叠不做动效；lucide 按需 import；新增代码全走懒加载路由级 `React.lazy`（方案 A 下），首屏 `/` 不因此变大。
